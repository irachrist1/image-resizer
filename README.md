# image-resizer

Static image resizer demo site — HTML/CSS/JS front-end exercise.

## The problem

You are learning client-side image manipulation basics and responsive gallery layouts.

## What it does

Multi-page static site (`index.html`, `about.html`) with CSS and JS in `css/` and `js/` folders for image display and resize interactions.

## Install

```bash
git clone https://github.com/irachrist1/image-resizer.git && cd image-resizer
open index.html
```

## How it works

- **Client-side image handling.** JS reads and displays image dimensions — canvas or img element patterns.
- **Static site structure.** About page + main tool — small multi-page pattern.
- **CSS layout for galleries.** Image grids and responsive breakpoints — common freelance skill.
